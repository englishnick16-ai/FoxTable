# Контекст проекта FoxTable

Новый проект, создан 11 ноября 2026. До создания проверена рабочая папка: существующего Unity-проекта, Unity Editor и Unity MCP не обнаружено. Пакеты стороннего MCP не устанавливались. Работа с исходниками возможна без редактора; живые проверки недоступны.

## Среда и архитектура

- Базовая версия: Unity 6000.0.62f1; Built-in Render Pipeline, без URP/HDRP.
- Цель: Android 8+ (API 26), ARM64/IL2CPP. Ориентация автоматическая, безопасная область экрана учитывается процентными отступами.
- Шрифт: DejaVu Sans с кириллицей, лицензия в `Docs/DejaVu-LICENSE.txt`.
- UI: UI Toolkit, C#-создание дерева, `Resources/FoxTheme.tss` импортирует стандартную тему, собственные стили в `FoxTable.uss`.
- Ввод: стандартные PointerEvent UI Toolkit; отдельный Input System не используется. Pinch и drag обрабатываются в `BattleBoard`.
- Сеть: UnityWebRequest + JSON, серверный авторитет; нет NGO/Mirror/Photon/Relay.
- Сервер: Python 3.10+, SQLite WAL, один процесс и RLock вокруг изменяющих операций, REST/HTTP-опрос.
- Сцена генерируется редакторным меню через Unity API; YAML сцены вручную не создан. Точка входа — RuntimeInitializeOnLoadMethod в FoxTableApp.
- Runtime-код в `Assets/FoxTable/Runtime`; Editor-код в `Assets/FoxTable/Editor`; asmdef пока нет, используются Assembly-CSharp и редакторная сборка.

## Владение

- RoomClient: сохранённая сессия, очередь команд, повтор с requestId, опрос и загрузка карт.
- FoxTableApp: UI, навигация, Android picker callback, применение снимков к представлению.
- BattleBoard: проекция сцены, жесты, локальное предварительное перемещение, сетка/туман/шаблоны.
- FoxTablePanels: дополнительные мобильные панели действий, освещения, профиля и предпросмотра.
- Server/visibility.py: пересечение отрезков, обзор клеток, свет и аддитивная миграция v1 → v2.
- Models: сериализуемые DTO и минимальный JSON-encoder для операций с отсутствующими необязательными полями.
- Server/server.py: единственный владелец боевого состояния, прав и результатов кубиков.
- FoxTableBuild: подготовка сцены/настроек и сборки Android.
- FoxGallery.java: Android ACTION_OPEN_DOCUMENT, callback с base64 без общих разрешений на хранилище.

## Подтверждено и не подтверждено

49 серверных тестов прошли; синтаксис C#/Java разобран. Компиляция Unity, импорт ресурсов/метаданных, PlayerSettings API, тема UI, сборка Android и жизненный цикл пикера **не подтверждены**. Не называть проект готовым APK. Текущие ограничения и план проверок в `README.md` и `Docs/VALIDATION.md`.

## Правила продолжения

Сначала импорт/Console в Unity, затем два клиента и Android. Сохранять серверный авторитет; не доверять клиентским результатам кубиков или общей замене снимка. Не менять GUID после импорта. Не устанавливать Unity MCP автоматически. Не выдавать fog-оверлей за криптографическое сокрытие фонового изображения. Не хранить реальные ключи или SQLite-базы в исходном архиве.

## Обновление 0.2

Снимки v2 включают barriers, currentCells/exploredCells, профили зрения/света, слои, временные HP и действия жетонов. На сервере хранится exploredBy, который никогда не передаётся клиентам. GM получает пустые currentCells/exploredCells (обязательные массивы для JsonUtility); игрок получает вычисленные. Схема SQLite прежняя, новые поля живут в JSON. Перед миграцией сохранить backup.

Предпросмотр POST /api/rooms/{code}/preview доступен только GM и не записывает историю. RoomClient запрещает действия в режиме предпросмотра и не переключает вид при незавершённой очереди. Сообщения combat содержат refs и фильтруются по видимым жетонам; базовое изображение карты всё ещё передаётся целиком.
