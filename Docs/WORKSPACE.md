# FoxTable 0.4 — управление на телефоне

1. На стартовом экране нажать «Играть локально». Онлайн-комнаты раскрываются отдельно.
2. «Модели» → категория → фигурка → коснуться карты. Можно поставить несколько копий; «Готово» завершает расстановку. Двумя пальцами карта масштабируется.
3. В режиме «Двигать» тянуть фигуру; пустое место двигает карту. Нажатие выбирает фигуру без открытия окна. Контекстная строка содержит HP и «Действия».
4. Для декора «Действия» позволяют поворот, закрепление, скрытие, копию и карточку. Закреплённая фигура выбирается, но не сдвигается жестом. «Инструменты → Слой» помогает выбрать декор под героем.
5. «Карта → Загрузить картинку» открывает выбор PNG/JPEG. Предпросмотр показывает сетку; указать клетки по ширине, выполнить подгонку, подтвердить. Точные размеры/пиксели/сдвиг/цвет/яркость находятся в раскрываемом блоке. Фон сохраняет пропорции. Лимит6МБ/16МП/8192по стороне.
6. «Карта → Настроить сетку» позволяет подгонку уже загруженной картинки; изменения применяются только кнопкой. Ноль пикселей в клетке — вписывание без растяжения.
7. «Инструменты» содержит туман, шаблоны, стены, двери и слой выбора. Декоративная дверь из каталога — картинка; игровая дверь создаётся инструментом преград.
8. «Бой» ведёт инициативу и раунды. Кубики открывают журнал с результатом. Текст сообщения не теряется при обновлении журнала.
9. «Отменить» возвращает последнее локальное действие (до20), включая удалённые фигуры; историю отмены перезапуск не сохраняет.
10. «Меню → Сохранить и выйти» сохраняет локальную игру. Удаление приложения удаляет локальные данные. Онлайн-выход в меню сохраняет личный доступ; «забыть» — отдельная кнопка.

Это собственный2Dстол с функциями по мотивам Owlbear/Roll20, а не полная копия их платформ. Нет3Dсцены, голосовой связи, полной базы правил или магазина материалов. Полный функциональный и визуальный тест на телефоне обязателен.
