# Проверка FoxTable 0.2

Дата: 11 ноября 2026. APK как артефакт: **Ready with limitations** — Unity Build Automation №4 успешно создал пакет; упаковка проверена. Работа приложения на устройстве: **Not validated**. Публичный сервер не запущен. Серверные сценарии ниже прошли ранее; после изменений только Android-сборки они не запускались повторно.

## Подтверждённые результаты

- `python3 -m unittest discover -s tests -v`: 49 тестов, 49 успешных.
- Два независимых HTTP-клиента: мастер создаёт комнату, игрок входит по приглашению, мастер назначает владельца, игрок двигает жетон, мастер получает новую позицию.
- Проверены отказы доступа: без ключа, чужая комната, чужой жетон, закрытая комната, неправильный/устаревший ключ приглашения, мастерские операции от игрока.
- Проверены скрытые жетоны, ручной туман, приватные заметки и сцены, недоступные игроку.
- Проверены кубики, HP и состояния, инициатива и переход раунда, переключение/удаление сцены.
- Проверены повтор команды с тем же requestId, откат некорректной команды, параллельные сообщения без потери.
- Проверены сохранение/перечитывание SQLite, позднее подключение, восстановление роли по личному ключу.
- Проверены загрузка/авторизация карт и отклонение некорректного заголовка/чрезмерных размеров.
- C# и Java разобраны Tree-sitter без синтаксических ошибок. Это подтверждает синтаксис, но не доступность Unity/Android API и не компиляцию.
- JSON/XML конфигурации разобраны стандартными парсерами, GUID метаданных проверены на уникальность.

## Дополнительные проверки версии 0.2

- Видимость перекрывается стенами/дверями, а открытие двери возвращает противника в снимок игрока. Это также проверено через HTTP между участниками.
- Окно пропускает свет/обзор и блокирует ход, закрытая дверь блокирует оба; проверены секретность, замки, близость игрока и отсутствие прохода через преграды.
- Свет и тёмное зрение работают в темноте; состояние «Ослеплён» оставляет видимой только собственную клетку. Видимость индивидуальна, общий обзор включается отдельно.
- Исследованная карта сохраняется после выхода из обзора и перезапуска базы, а противники вне текущего обзора не передаются.
- Предпросмотр GM совпадает с видом игрока, не меняет историю и запрещён игроку.
- Приватный слой и сообщения скрытых противников отфильтрованы; заблокированный жетон и объекты карты игрок не двигает.
- Бюджет скорости, чужой ход и сброс на новом ходу проверены.
- Урон сначала снимает временные HP; лечение ограничено максимумом. Крит удваивает кубики (фиксированный модификатор не удваивается), натуральная 1 промахивается, концентрация выводит СЛ.
- Атака проверяет дистанцию, видимость и преграды. Действия жетона используют сохранённые формулы, игрок их не переопределяет.
- Миграция v1 → v2 сохраняет ID и существующие поля; дубликат жетона получает новый ID и сохраняет профиль.

## Следующая проверка на устройстве

1. Открыть проект и сохранить первичный Console log, не очищая ошибки.
2. Выполнить `FoxTable/1. Prepare project`; проверить сцену и Build Settings.
3. Запустить сервер, войти мастером из Editor.
4. Собрать development APK и войти игроком с телефона. Назначить жетон игроку.
5. Проверить перемещение в обе стороны, туман, секретные заметки, чат, кубики и инициативу.
6. Выключить сеть телефона, выполнить действие, включить сеть и убедиться, что действие применяется ровно один раз.
7. Повернуть устройство во время жеста; проверить вырезы экрана и экранную клавиатуру.
8. Выбрать настоящие PNG и JPEG через Android Documents; проверить отмену, файл больше лимита и повреждённый файл.
9. Перезапустить приложение и сервер; восстановить роль по личному ключу.
10. Проверить рисование стен, открывание/запирание дверей, факел и тёмное зрение на двух клиентах.
11. Проверить «Глазами игрока», возвращение в GM, память карты, приватный слой и границы ручного тумана.
12. Проверить быстрые атаки и подсветку попадания/крита, макросы, временные HP и бюджет движения.
13. Собрать обычный ARM64/IL2CPP APK, проверить HTTPS на двух устройствах.

До выполнения этих шагов статус Android-приложения не повышать до готового.
